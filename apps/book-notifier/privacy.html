book-notifier

プライバシーポリシー

対象ツール: book-notifier

1. はじめに

本プライバシーポリシーは、Shunki72が個人で開発・利用する book-notifier（以下「本ツール」）における、 Googleユーザーデータの取り扱いについて説明するものです。

2. アクセスするGoogleユーザーデータ

本ツールは、Google Calendar APIを通じて、 ユーザーが許可した範囲のGoogleカレンダーデータにアクセスします。 これには、予定のタイトル、日時、説明、参加者など、 使用するOAuthスコープで許可された情報が含まれる場合があります。

3. 利用目的

取得したGoogleユーザーデータは、カレンダー予定の取得、表示、 作成、更新その他、本ツールが提供するカレンダー管理機能を 実行する目的でのみ利用します。

4. データの保存

本ツールはローカル環境で動作します。 OAuth認証に必要な認証情報またはトークンを保存する場合は、 ツールを実行するユーザーのローカル環境に保存します。 Googleカレンダーから取得したデータを恒久的に外部サーバーへ 保存することはありません。

5. 第三者への共有

Googleユーザーデータを、法令に基づき必要となる場合を除き、 第三者へ販売、提供または共有しません。

6. 広告利用

Googleユーザーデータを広告、広告配信、ユーザープロファイリングのために 利用しません。

7. Google API Services User Data Policy

本ツールによるGoogle APIから取得した情報の利用は、 Google API Services User Data Policy に従い、 Limited Use要件が適用される場合はこれを遵守します。

8. アクセス権の取り消し

ユーザーはGoogleアカウントのセキュリティ設定から、 本ツールに付与したアクセス権をいつでも取り消すことができます。

9. ポリシーの変更

本ツールの機能またはGoogleユーザーデータの取り扱い方法を変更した場合、 必要に応じて本ポリシーを更新します。
